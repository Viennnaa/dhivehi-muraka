Where the outlines came from

Every Thaana outline here was placed by hand, one point at a time, over several days.

An existing Thaana face sat on screen while drawing, the way a printed specimen would — but not one of its outlines is in this font. The build checks each letter against that reference on every run and refuses any glyph that shares coordinates with it. Fifty letters, fifty passes.

The Latin is Inter, merged under the same open licence and credited in the font's name table. No Thaana glyph comes from it.
